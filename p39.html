Box Model Components

Every element consists of: Content → Padding → Border → Margin

Content with Padding, Border, and Margin
.box-model-demo { background: #3498db; /* Content area */ padding: 20px; /* Space inside element */ border: 10px solid #e74c3c; /* Border around padding */ margin: 30px; /* Space outside element */ }

Individual Components

CONTENT
200px × 100px
PADDING - 25px all sides
BORDER - 15px solid border
MARGIN - 30px all sides
.content-demo { width: 200px; height: 100px; } .padding-demo { padding: 25px; } .border-demo { border: 15px solid #c0392b; } .margin-demo { margin: 30px; }

Box-Sizing Property

content-box (default)

Width: 200px
+ Padding: 40px
+ Border: 10px
= Total: 250px

border-box

Width: 200px
(includes padding
and border)
= Total: 200px
.content-box { box-sizing: content-box; width: 200px; } /* Total: 250px */ .border-box { box-sizing: border-box; width: 200px; } /* Total: 200px */

Interactive Box Model

Hover over the box to see properties change:

Hover over me!

.interactive-box:hover { margin: 30px auto; /* Increased margin */ padding: 30px; /* Increased padding */ border-width: 5px; /* Thicker border */ }

Box Model Calculation:

Total Width = Content Width + Padding + Border + Margin

Example: 200px + 40px + 10px + 60px = 310px total space
