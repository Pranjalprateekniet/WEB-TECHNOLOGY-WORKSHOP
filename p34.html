What are Block Elements?

Block elements take full width available and start on new lines:

  • Take up full width by default
  • Start on a new line
  • Stack vertically
  • Can have width, height, margin, padding

Common Block Elements

<div> - Generic block container

<p> - Paragraph element

<h3> - Heading element

div, p, h1, h2, h3 { display: block; }
